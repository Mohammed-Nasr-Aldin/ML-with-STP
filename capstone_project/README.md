## 📊 Summary of Technical Results
* **Target Objective**: Classifying customer creditworthiness into **Good**, **Standard**, or **Poor**.
* **Data Scale**: 100,000 labeled instances cleansed of corrupt records and imputed via Median/Mode techniques.
* **Key Performance Indicator**: Random Forest Classifier reached **76% test accuracy** using an optimal set of 9 financial attributes.
